# ABSTRACT

## **SURAKSHA – A Rule-Based Vulnerability Scanner**

The rapid growth of web applications, cloud computing, and network-based services has significantly increased cybersecurity threats, making vulnerability assessment an essential part of securing digital infrastructure. Security weaknesses such as SQL Injection (SQLi), Cross-Site Scripting (XSS), insecure configurations, exposed network services, and weak SSL/TLS implementations can lead to unauthorized access, data breaches, and service disruption. SURAKSHA is developed as an intelligent cybersecurity platform that combines rule-based vulnerability detection with machine learning–based network risk prediction to help users identify security flaws, evaluate network exposure, and improve the overall security posture of web applications and network systems.

Existing vulnerability assessment solutions are often designed for specific tasks such as web application scanning, network scanning, or SSL analysis, requiring multiple standalone tools to perform a complete security assessment. This increases operational complexity, requires manual correlation of scan results, and makes it difficult to prioritize vulnerabilities efficiently. Most traditional scanners also rely only on rule-based detection and do not provide intelligent risk prediction based on the characteristics of detected network services, limiting their effectiveness in supporting security decision-making.

The proposed system, SURAKSHA, integrates Web Vulnerability Assessment, Network Reconnaissance, SSL Security Analysis, Protocol Analysis, CVE Mapping, and AI-assisted Network Risk Prediction within a single platform. It detects SQL Injection (SQLi), Cross-Site Scripting (XSS), missing HTTP security headers, exposed sensitive directories, server information disclosure, and SSL/TLS configuration weaknesses. The network scanning module performs host discovery, port scanning, service detection, version detection, banner grabbing, and operating system fingerprinting using Nmap. Detected services are mapped to known Common Vulnerabilities and Exposures (CVEs), while a Random Forest machine learning model predicts the overall network security risk by analyzing features such as port number, protocol, service name, service version, operating system, and the number of open ports. The platform presents results through centralized dashboards, severity-based risk classification, confidence scores, and downloadable security reports, enabling faster vulnerability analysis and informed security decisions.

The system supports two categories of users. Public users can perform web and network security scans, view detected vulnerabilities, analyze risk levels, and download security reports. Administrators can manage user accounts, maintain vulnerability information, monitor scan activities, update security data, and oversee the overall operation of the platform through an administrative dashboard.
SURAKSHA is developed using Python and Flask for backend development, HTML5, CSS3, Bootstrap 5, and JavaScript for the frontend, and SQLite for database management. The platform utilizes Python-Nmap for network reconnaissance, Requests and SSL libraries for web and SSL analysis, and Scikit-learn with the Random Forest algorithm for AI-based network risk prediction. Rule-based vulnerability detection, CVE correlation, protocol analysis, security header analysis, banner grabbing, operating system fingerprinting, and machine learning together provide an efficient and comprehensive cybersecurity solution for educational and authorized security assessment.
